Map View Behaviors

Single layer active

Counties colored by that layer's score (0–100 gradient). Legend shows the layer name and color scale.

Multiple layers active

Counties colored by minimum score across active layers. Gold highlight on counties that pass all layers above threshold. Intersection count shown in sidebar.

Click county

Popup shows all layer scores for that county. Right panel populates with key metrics. "Full Detail" opens County view with all data, properties, and news.

Threshold slider

Each layer card has an optional score threshold (default 0). Slide up to filter — only counties above threshold are colored. Intersection count updates live.
