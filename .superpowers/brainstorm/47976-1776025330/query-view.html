Query Flow

💬
1. Ask or Write

Type a natural language question (Gemini generates SQL) or write SQL directly. Gemini gets table schemas as context via Firebase AI SDK.

⚡
2. Review & Run

Generated SQL is shown and editable before execution. Click Run to execute against DuckDB-WASM. Results render as a sortable table.

💾
3. Save & Act

Save as a named analysis (tagged to a thesis). Pin results to Map as a layer. Export to XLSX. Add to a partner presentation deck.
