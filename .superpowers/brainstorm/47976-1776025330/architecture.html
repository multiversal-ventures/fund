Key Concepts

Layers

Each scoring model (market score, Akshay's thesis, Holly's ops, DC score) is a layer. Toggle them on/off on the map. When multiple layers are active, see the intersection — counties that score well across all.

Analyses

A saved SQL query with a name, description, and owner. You write SQL or use Gemini NL→SQL. Results can be pinned to map, exported to XLSX, or included in a presentation.

Data Sources

Pipeline Parquet files + team uploads. Anyone can upload XLSX/CSV — it gets converted to Parquet in-browser (via DuckDB) and stored in Firebase Storage. Appears as a queryable table immediately.

Present

Curate a set of analyses + map views into a presentation. Generate a one-time link (Cloud Function creates a token with expiry). Partners see a read-only view — no auth, no SQL, just the curated story.
